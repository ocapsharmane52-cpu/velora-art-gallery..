
# VELORA - Digital Art Gallery

## Project Description

VELORA is a creative digital art gallery
designed to showcase beautiful digital artworks,
abstract compositions, and artistic designs.

The website uses a dark brown and warm beige
color palette to create an elegant and artistic
visual experience.

## Technologies Used

- HTML5
- CSS3
- SVG Artwork

No JavaScript or JavaScript frameworks are used.

## Website Pages

1. Home - Introduction and featured artworks.
2. About - Information about VELORA.
3. Gallery - Collection of digital artworks.

## Features

- Dark brown artistic theme
- Responsive website layout
- Navigation between pages
- CSS hover effects
- Artwork gallery
- HTML5 and CSS3 only

## How to Open

1. Open the project folder.
2. Double-click index.html.
3. Open the website using your browser.
4. Navigate using Home, About, and Gallery.
